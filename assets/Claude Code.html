Se você ainda não criou

  1. Entre em github.com com a conta Razzano380.
  2. Clique no +, no canto superior direito, e depois em New repository.
  3. Em Repository name, escreva exatamente proxima-dose.
  4. Marque Public.
  5. Clique em Create repository.
  6. Na página seguinte, clique em uploading an existing file e arraste o README.md.
  7. Para o logo, clique em Add file → Upload files e arraste o logo.png e o logo.svg. Depois, mova os dois para a pasta assets, que é onde o README procura o logo. Se for mais fácil, envie a pasta assets inteira arrastando a própria pasta do computador.
  8. Clique em Commit changes.

Se você já criou e mesmo assim não abre

  • Repositório privado: vá em Settings → General, desça até Danger Zone, clique em Change visibility e escolha Public.
  • Nome diferente: veja na sua página de perfil (github.com/Razzano380) qual nome ficou. Por exemplo, Proxima-Dose ou proxima_dose geram outro link.
  • Usuário diferente: confira se o seu usuário é mesmo Razzano380, olhando no canto superior direito do GitHub.
